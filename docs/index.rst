###############################
Python SDK for the Highspot API
###############################
Welcome to the official documentation for the Python SDK for the Highspot API.

.. important:: Version 2.0.0 and newer of the SDK require Python 3.10 or newer (and older than 3.14). Version 1.0.0
               is the final release that supports Python versions older than 3.10 and can be installed using
               ``pip install "highspot<2"``.
